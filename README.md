# Quiz App

## 📌 Description
A simple Android Quiz Application developed using Java in Android Studio. The app displays multiple-choice questions, allows users to select an answer, and shows whether the selected answer is correct or incorrect.

## ✨ Features
- Start Quiz screen
- Multiple-choice questions
- Correct/Wrong answer feedback
- Next button to move through the quiz
- Simple and user-friendly interface

## 🛠 Technologies Used
- Java
- Android Studio
- XML
- Android SDK

## 📱 How to Run
1. Clone this repository.
2. Open the project in Android Studio.
3. Build and run the app on an emulator or Android device.
